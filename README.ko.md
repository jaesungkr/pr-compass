# PR Compass

[English](README.md) · **한국어**

**지금 어떤 PR부터 살펴봐야 할까요?**

다른 사람·조직의 공개 저장소에 보낸 PR을 읽고, 확인 순서와 이유·다음 행동·링크를 정리하는 작은 CLI입니다.
AI·서버·외부 패키지·프로필 장식·쓰기 권한이 필요하지 않습니다.

## 실행

Node.js 22 이상에서:

```sh
git clone https://github.com/jaesungkr/pr-compass.git
cd pr-compass
node src/cli.mjs YOUR_USERNAME --language ko
```

별도 패키지 설치는 필요 없습니다. 실행할 코드를 확인하고, 자동으로 최신 버전을 따라가기보다 검토한 커밋을 사용하세요.

```sh
node src/cli.mjs YOUR_USERNAME --limit 3 --language ko
node src/cli.mjs YOUR_USERNAME --json
node src/cli.mjs --help
```

기본값은 **열린 PR 최대 5개 + 최근 병합 PR 최대 5개**입니다. 전체 PR을 모두 확인했다는 뜻이 아닙니다.
조회 결과와 표시 범위를 보고 필요하면 `--limit`을 20까지 늘릴 수 있습니다.
과거의 ‘병합 없이 닫힌 PR’ 전체를 검색하지는 않습니다. 조회 도중 닫힌 PR이 확인되면 병합 없이 닫힘으로 구분합니다.

## 네 가지 분류

- **확인 필요**: 수정 요청 리뷰, 실패 검사, 조치가 필요한 검사, 초안 등입니다.
  실패가 반드시 내 코드 때문인 것은 아니고 이전 수정 요청이 이미 해결됐을 수도 있으므로 근거를 먼저 확인합니다.
- **대기**: 검사가 진행 중이거나, 현재 확인 가능한 검사·리뷰에서 뚜렷한 조치 신호가 발견되지 않은 상태입니다.
  상대방이 답해야 한다거나 승인 요건이 충족됐다거나 병합 가능하다는 뜻은 아닙니다.
- **완료**: GitHub가 명시한 병합 또는 병합 없이 닫힘입니다. 두 결과를 구별하며 닫힘을 성공으로 포장하지 않습니다.
- **판단 불가**: 정보 누락·부분 조회·공개 HEAD 검사 없음 등입니다. 검사 없음은 성공이 아닙니다.

일부 정보가 없어도 확실한 실패나 수정 요청이 있으면 먼저 확인할 항목으로 보여주며 제한을 함께 표시합니다.
병합·닫힘 상태는 과거 검사 실패보다 우선합니다.

## 읽는 범위

**조회 대상 사용자와 base 저장소 소유자가 다른 공개 PR**만 포함합니다. 소유자 비교는 대소문자를 구별하지 않습니다.
본인 저장소·본인 포크는 제외하고 조직 소유 저장소는 포함합니다. 본인 포크에서 다른 프로젝트로 보낸 PR은 포함합니다.

PR 상태, 리뷰어별 최신 유효 결정, 확인한 **HEAD SHA**의 check runs와 legacy statuses를 읽습니다.
필수 검사·브랜치 보호·대화 해결·merge queue·테스트 병합 커밋은 판단하지 않습니다.
리뷰 기록은 병합 정책 충족 여부가 아니며 조회 중에도 PR 상태나 검색 색인은 바뀔 수 있습니다.

분류별 최근 업데이트순 최대 100건에서 표본을 가져옵니다. 병합 목록은 그 안에서 실제 병합일순으로 정렬하므로
전체 이력의 최신 병합순을 보장하지 않습니다. 실시간 감시 도구가 아닌 제한된 스냅샷입니다.

## 인증·오류 처리

GitHub 공개 API 한도 내에서는 토큰 없이 사용할 수 있습니다.
선택적으로 `GITHUB_TOKEN` **환경변수**를 읽지만 명령줄 인자로 받지 않습니다.
토큰을 명령줄·커밋·스크린샷·이슈에 넣지 마세요. 이 도구를 위해 권한을 늘릴 필요는 없습니다.
전달된 토큰이 더 많은 정보에 접근할 수 있어도 공개 데이터의 GET 요청만 합니다.

요청은 순차적·제한된 범위로 실행하며 시간 제한이 있습니다.
인증 없이 연달아 실행하면 API 한도에 걸릴 수 있으므로 반복 재시도보다 초기화를 기다리세요.
검색 실패·불완전 검색·공개 여부 확인 실패는 거짓 0건 대신 보고를 중단합니다.
검사·리뷰의 일부 조회 실패는 판단 불가로 표시합니다.

종료 코드 **0**은 조회·출력 성공이지 PR 상태가 정상이라는 뜻이 아닙니다.
잘못된 입력이나 조회 실패는 **1**입니다. `--json`은 stdout에 JSON 문서 하나만 출력하고 오류는 stderr에 출력합니다.
직접 출력 리디렉션을 하지 않는 한 파일을 생성하거나 수정하지 않습니다.

환경변수 기본값: `PR_COMPASS_USERNAME`, `PR_COMPASS_LIMIT`, `PR_COMPASS_LANGUAGE`.
명령줄 옵션이 환경변수보다 우선합니다.

## 이전 프로필 버전에서 전환

현재 CLI는 **README 수정·이미지 생성·커밋·예약 실행을 하지 않습니다**.
main에서 이전 composite Action과 프로필용 workflow 예제도 제거했습니다.

예전 커밋에 고정한 프로필 워크플로가 있다면 이 저장소를 업데이트하는 것만으로 멈추지 않습니다.
프로필 저장소에서 해당 워크플로를 제거하고, 필요 없다면 생성된 마커 영역과 파일도 지우세요.
과거 커밋에는 과거 동작이 남습니다. 기존 Action의 pin만 현재 CLI 커밋으로 바꾸면 안 됩니다.

## 개발

```sh
node --test
```

실행·테스트 외부 의존성이 없습니다. CI는 Node 22·24를 검사합니다.
분류 우선순위·누락 정보·이스케이프·공개/외부 경계·CLI·쓰기 없음 계약을 테스트합니다.
구현과 테스트에 AI의 도움을 사용했습니다.
